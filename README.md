# process

Project planning repository for a maintenance service platform (mobile + portable web).

## Overview

This repository captures the planning, SOP, and management framework for a product where:
- Customers raise maintenance requests with location and address details.
- Requests are assigned area-wise to maintenance staff.
- Staff execute onsite work and close tasks.
- Payments are tracked through card, wallet, or cash.

## Roles

- **Company Owner**: business strategy, approvals, and governance.
- **Maintenance Owner**: operations control, assignment quality, and performance.
- **Customer**: request creation, tracking, payment, and feedback.
- **Maintenance Staff**: task acceptance, visit execution, and completion proof.
